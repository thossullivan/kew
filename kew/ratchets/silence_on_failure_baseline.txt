# Silence-on-failure debt ledger (A4 / W2.1) — NOT an approval list.
#
# Every line is an `except` handler that returns or assigns a clean default
# while recording nothing about why it defaulted.
# The convention is in CONTRIBUTING.md, "No silent clean defaults"; the gate is
# tests/test_silence_on_failure.py.
#
# Ledger size at head: 210 handlers in 195 functions.
# Burn-down work is tracked in #1764.
# Legitimate-by-design entries include tolerant stream parsers such as analytics.py::_line_assistant_cache_read.
# Also by construction, not debt: handlers that assign None and fail closed on it later
# (graph/driver/tick.py verdict = None then `is not False`; orchestrator.py pgid = None after
# proc.terminate(); canary_live.py:653). #1764 need not re-decide them.
# Keys are per function, so a net-zero handler swap within one function can pass.
#
# Format: <file>::<qualname> <number of such handlers in that function>
#
# The gate is a ratchet in both directions: a new site fails until it is fixed
# or added here deliberately, and a fixed site must be removed here — so this
# file measures the remaining corpus rather than hiding it.
#
# The A2 site (`src/kew/cli/__init__.py::_status_queue_counts::_count`, a gh
# failure rendering an all-zero healthy queue) is the first scheduled fix, W2.2.
# Also by construction (#2569): publication_materialize.py treats a missing path as
# the answer (_remove/_parents: nothing to remove; _write: nothing to replace) and
# stops pruning at the first non-empty directory (_prune); every other OSError there
# refuses the materialization. _disk_oid (#2591) answers None for a path it cannot
# read as a plain file or link, which marks that path for a rewrite — the fail-safe
# direction: the rewrite either repairs it or refuses.
